# NW Shore Fishing Guide

A beginners' interactive guide to shore/estuary fishing in NW England (Mersey, Dee, Duddon).
One self-contained HTML file, vanilla JS, no build step. Works offline except map tiles.

**Live:** https://crgz13.github.io/fishing-field-guide/

Design principles, research corrections, roadmap, and the rejected-ideas list live in
[CLAUDE.md](CLAUDE.md) — read it before changing anything.
